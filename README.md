# 🌏 Si DESKA - Sistem Informasi Data Entri Statistik Kabupaten

> **Si DESKA** adalah sistem data statistik berbasis **verifikasi blockchain** untuk **35 Kecamatan** dan **339 Desa/Kelurahan** di Kabupaten Pandeglang.

---

## ✨ Fitur Utama

- 📊 **48 Sektor Statistik** - Lengkap semua bidang pembangunan
- 🏡 **Data RT/RW** - Dari 12.500+ RT dan 2.500+ RW
- ⭐ **Sistem Poin & Reputasi** - Apresiasi kontributor data
- 🔗 **Verifikasi Blockchain** - Bukti keaslian data (bukan aset keuangan)
- 🇮🇩 **Sesuai Regulasi** - UU PDP, Perpres SDI, SPBE
