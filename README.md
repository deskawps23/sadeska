> **Si DESKA** (Sistem Informasi Data Entri Statistika Kabupaten) adalah sistem data statistik berbasis **Blockchain Real-Time** untuk Kabupaten Pandeglang.

## ✨ Fitur Utama

- 🌏 **Blockchain Visual** - Kurva bergerak seperti rantai blockchain
- ⚡ **Real-Time Update** - Data masuk setiap detik (auto-generate)
- 🎨 **UI Neon Futuristic** - Efek glow dan animasi modern
- 🔄 **Simulasi Mining** - Proof-of-work setiap 3 detik
- 📊 **48 Sektor** - Lengkap semua bidang pembangunan
- 🏡 **Data RT/RW** - Dari 12.500+ RT dan 2.500+ RW
